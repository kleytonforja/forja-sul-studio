# Forja Sul Studio

Landing page institucional da Forja Sul Studio.

## Sobre o projeto

Projeto desenvolvido como laboratório prático de vibe coding, utilizando VS Code, Git, GitHub, HTML, CSS, JavaScript e integração com Higgsfield via MCP.

## Serviços apresentados

- Criação de sites
- Landing pages
- Dashboards
- CRM e sistemas personalizados
- Agentes com WhatsApp

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Higgsfield via MCP
